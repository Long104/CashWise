# Senzen — Section Suite Research

Status: Phase 1 research for landing-suite.md. Sources fetched 2026-08-23.

## Composer.trade full-page section map [official — composer.trade]

1. **Hero** (split/centered): value prop + CTA, AI chat mockup adjacent, volume stats, testimonial logos.
2. **AI Strategy Creation** (band): chat interface user↔AI, backtest result inline, performance chart, per-section CTA ("Create with AI").
3. **Automation Demo** (split): holdings BEFORE/AFTER rows, rebalancing explained, "More automation" CTA.
4. **Discover Categories** (band): strategy types, if-this-then-that logic blocks, community showcase, CTA.
5. **Editor Suite** (band): editor mockup, conditional logic, backtest chart, allocation graph, CTA.
6. **Community** (split): testimonials, user strategy examples, social proof.
7. **Pricing** (band): plan options, simple subscription framing.
8. **FAQ** (accordion): product, setup, fees, security questions.
9. **Final CTA** + footer.

Pattern: every band is text-explains + product-visual-proves, each with ONE CTA. Rhythm alternates split ↔ band.

## Stripe structural notes [official — stripe.com]

- Product demos = split visual + text columns, code-first presentation beside UI demos.
- Feature highlights use VARIED bento sizing — never uniform card walls.
- Trust metrics (uptime, volume, countries) integrated inside feature narratives.
- Per-feature "Explore" text links, not repeated big buttons.

## Linear structural notes [official — linear.app]

- Feature sections alternate: split layouts (text left, product visual right), then flip.
- Real product screenshots in-page, not abstract illustrations.
- FAQ accordion AFTER features, BEFORE final CTA.
- Editorial spacing; deliberate whitespace; clean 3-level hierarchy (title/desc/CTA).

## Shared anti-slop principles

- Text-first hierarchy; visuals prove the claim the text just made.
- Varied/asymmetric grids — no uniform 3-col icon card walls.
- No gradient blobs, no glassmorphism, no generic stock illustration.
- ONE CTA per section, styled as quiet text link or single pill.
- Restraint: motion limited to hover micro-interactions; no scroll-jacking.
- Real product surfaces (chat, ledger, editor) over marketing abstractions.

## Recommendations for Senzen

| Composer archetype | Senzen translation |
|---|---|
| AI Strategy Creation chat | **AI Plan Demo**: user asks in plain language → Senzen replies with plan-logic block (mirrors real /ws chat concept) |
| Automation holdings before/after | **Automation section**: paycheck allocation rows Before (all in checking) vs After (split: savings/buffer/invest) with green deltas |
| Editor/logic blocks | Plan-Logic Block already ownable (keep, refine) |
| — (Stripe bento, varied) | **Highlights band**: 4 editorial numbered rows w/ green dots, varied width, no cards |
| Linear FAQ-after-features | **FAQ accordion** after Weekly Clarity, before footer |
| Linear product-screenshot honesty | Weekly ledger rows = real product surface, CSS-only |

Sequencing law (from all three): Hero → proof stats → demo → automation → highlights → feature depth → FAQ → footer. Alternating split/band rhythm. Footer always last, pinned.

## Structural notes applied to Senzen DNA

- Dot-matrix motif stays the ONLY texture; ≥3 placements, never behind body text blocks.
- Composer's chat demo is Composer's visual — Senzen borrows the STRUCTURE (conversation → artifact) with own styling: white panel, 1px #E5E5E5 border, mono logic rows, green state dots.
- Before/after rows use mono tabular numerals, green for deltas only.
